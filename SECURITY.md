# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x (initial development) | yes |
| older releases | no |

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub Security Advisories — use **Report a vulnerability** on the repository's Security tab. Never open a public issue for a security problem.

You can expect a first response within 72 hours, followed by status updates until a fix ships.
